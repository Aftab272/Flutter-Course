# 🎓 Student & Canteen Management System

A simple **Dart Console Program** created to practice basic Dart programming concepts, including variables, data types, `if/else`, collections, loops, and bill calculation.

## 📌 Project Overview

This project contains a student profile system and a canteen management system.

The program:

* Stores student information
* Checks student access
* Provides discounts based on CGPA
* Displays a canteen menu
* Stores food items and prices using Lists
* Calculates order cost
* Calculates student discount
* Displays the final bill

### Task 1 – Student Profile Setup

Used different Dart data types:

* `String` – Student Name
* `int` – Student Age
* `double` – CGPA
* `bool` – Student Status

### Task 2 – Access & Discount System

Used `if/else` conditions to:

* Check whether the user is a student
* Grant or deny access
* Give a 10% discount when CGPA is 3.0 or higher
* Give a 5% discount when CGPA is below 3.0

### Task 3 – Canteen Management

Used Dart `List` collections to store:

* Burger
* Pizza
* Biryani
* Cold Drink

The program also stores the prices of these items.

### 🧾 Order / Bill Calculation

The program calculates:

* Item quantity
* Item price
* Total bill
* Discount amount
* Final bill

## ▶️ How to Run

### 1. Check Dart Installation

Open the VS Code terminal and run:

```bash
dart --version
```

### 2. Run the Program

Make sure you are inside the project folder containing `main.dart`.

Run:

```bash
dart run main.dart
```

You can also use:

```bash
dart main.dart
```
